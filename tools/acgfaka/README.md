================================================
 acg-faka + 纸SU  发卡完整步骤
================================================

结论先说：不用写插件、不用改 acg-faka。
         用它的「卡密池」就行，exe 导出、后台导入，两步。

------------------------------------------------
 为什么这样可行（源码依据）
------------------------------------------------

acg-faka 的卡密导入实现（app/Controller/Admin/Api/Card.php）：

    359|  $cards = preg_split('/\r\n|\n|\r/', $cards);   ← 一行一张卡
    381|  $list  = explode("║", $cardt);                 ← 字段用 ║ 分隔
    466|  if ($secret === '' || mb_strlen($secret) > 760) ← 卡密最长 760 字符

我们的签名卡密：约 160~200 字符 ✓ 远低于上限
编码是 URL-safe base64：只含 A-Z a-z 0-9 - _ 和点 ✓
    没有换行 ✓ 没有 ║ ✓ 没有 + / ✓
    ⇒ 导入不会被截断、不会被拆字段、不会被转义 ✓


================================================
 第一步：先把商品配好
================================================

后台 → 左侧「商品管理」→ 找到 PaperSU → 点「修改商品」

  【发货设置】标签页

    发货方式     ● 自动发货          ← 必须是这个
                 ○ 手动/插件发货

    卡密排序     ● 旧卡先发          ← 随便，建议旧卡先发
                 ○ 随机发卡
                 ○ 新卡先发

    发货留言     （可留空，或者写一句说明，会一起发给买家）

    联系方式     ● 任意（或按你喜好）

    邮件发送     看你需不需要邮件通知

  【商品限制】标签页（顺便确认）

    库存模式     要能按卡密池库存走（一般是「卡密库存」）
    限制购买     「每人限购」自己定（卖 VIP 一般建议 1）

  改完点右下角【保存】

★ 发货方式必须是「自动发货」。
  选成「手动/插件发货」的话，买家付款后订单会挂着等人发货 ✗


================================================
 第二步：exe 生成卡密
================================================

双击  D:\Users\code\Desktop\papersu-apk\papersu-license.exe

  【签发】页

    私钥      D:\Users\code\Desktop\papersu-apk\license-keys\private_key.pem
    公钥      D:\Users\code\Desktop\papersu-apk\license-keys\public_key.pem

    用户名     （随便，比如 批次20261006）
    等级       vip
    到期日     2027-12-31   （或者勾「永不过期」）
    张数       500          （最多 1000）

    点【生成】

  然后点【导出 TXT（一行一张）】

    存成 papersu-cards.txt

★ 想卖多少就签多少。500 张几秒钟。卖完再签一批接着导。


================================================
 第三步：导入 acg-faka（核心两步）
================================================

后台 → 左侧「卡密管理」

  1. 页面上方先【选择商品】—— 选「PaperSU」
     （不选商品直接上传，卡密会挂到错误的商品上）

  2. 点左上角【上传卡密】按钮

  3. 弹窗里把 papersu-cards.txt 的内容整个粘进去

     每行一张，长这样：
        eyJ1Ijoi5om5IiwidCI6InZpcCIsImV4cCI6IiIsIm4iOiI5OWQxOWNlOSJ9.MEUCIQDi52JQ...
        eyJ1Ijoi5om5IiwidCI6InZpcCIsImV4cCI6IiIsIm4iOiJhMWIyYzNkNCJ9.MEUCIQFk...
        ...

     ★ 不要加 BOM、不要加表头、不要加引号 —— 纯一行一张

  4. 确定

  成功会提示：「共计导入:500张卡密，成功:500张，失败：0张」

  ★ 如果失败数不是 0：
       - 检查是不是复制的时候多带了空行（空行会被当成一张空卡密）
       - 检查是不是每行都被换行截断了
       - 用记事本打开确认行数正好是 500


================================================
 第四步：验一遍（重要，别跳过）
================================================

  1. 卡密管理页面，确认「PaperSU」商品的库存显示 500

  2. 自己下一个单试试（可以设个 0.01 元的测试价，或者用管理员身份模拟）

  3. 看订单详情：发货内容是不是一串 eyJ... 开头的长卡密
     ⇒ 是 → 通了 ✓

  4. 拿这张卡密去手机上激活

     纸SU → 底部「我的」→「卡密激活」→ 粘贴 → 点【激活】
     显示「激活成功：vip」✓

     回「我的」→「VIP 功能」→「分区刷写」→ 能进去 ✓

  ★ 如果手机显示「签名对不上」：
       说明这张卡密不是这把私钥签的
       —— 检查 exe 里选的私钥，和编进 APK 的公钥是不是一对

  ★ 如果手机显示「已过期」：
       检查签发时的到期日


================================================
 第五步（可选）：推到授权站
================================================

作用：登记发了哪些卡密、限制一张能用几次、出问题能停用。
     不推也能用 —— 卡密本身离线就能验。

  1. 先按 tools/authsite/README.md 把授权站部署好

  2. 后台建表（SQLite 首次访问自动建；MySQL 手动导入 install.sql）

  3. exe → 【授权站 / 店铺】页

       授权站地址    https://你的域名
       共享密钥      你 config.php 里的 API_SECRET

       点【推送「签发」页列表里全部】

  4. 部署完了打开 /admin.php 就能看用量、停用卡密

  ★ 注意：授权站要单独加这条 nginx 规则，否则 config.php 能被直接下载
       location ~ ^/(config\.php|data/|lib\.php|install\.sql) { return 404; }

================================================
 两个坑，提前说
================================================

坑 1：卡密长度
    签名卡密约 160~200 字符，acg-faka 上限 760 —— 没问题 ✓
    但如果你以后自己改签名逻辑把它弄长了，注意别超

坑 2：不要用那 100 个 VIP-2025-0821-XXX
    短码里没有签名，应用不认 ✗
    它只能配合「授权站映射表」用（那个还没做）
    现在这一套必须用 exe 签出来的长卡密 ✓

 一句话总结
================================================

  exe 签 → 导出 TXT → 卡密管理上传 → 完事
